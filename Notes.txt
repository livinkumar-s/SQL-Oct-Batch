Constraints
---------------
>> rules applied to a cloumn to control type of data that can be inserted, updated or deleted.

PRIMARY KEY --> unique and no nulls. it identify each records uniquely.
FOREIGN KEY --> used to establish relationship between two tables.(referential integrity)
AUTO_INCREMENT --> generates serial number row by row.
UNIQUE --> No duplicates
NOT NULL --> No null values
DEFAULT --> adding default value to a cloumn.
CHECK --> add condition. CHECK (cond)

BETWEEN (inclusive)
---------
>> checks whether a value falls within a range. 
Ex... WHERE col BETWEEN num1 AND num2;

IN 
---
>> checks whether a value matches any value in a list.
Ex: ... WHERE col IN (v1,v2,v3....);

LIKE Operator 
--------------
>> Pattern Matching
Ex: ....WHERE strCol LIKE pattern;

wildcard:
% --> matches 0 to inf number of chars
_ --> matches only 1 char 

"a%" --> "anbu", "anshya", "a"....
"%a"
